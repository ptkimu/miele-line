# ミエーレ 空き枠のお知らせ

トータル・ビューティー・サロン ミエーレ の LINE公式アカウントで、
**空き枠のお知らせ** と **リッチメニュー** だけを動かすシステムです。
Cloudflare Workers + D1 で動きます。

急な空きが出たとき、受け取りを希望されたお客様にだけLINEでお知らせします。
30分あけてから Instagram のストーリーズに出すことで、
「LINEのほうが早い」という事実をつくり、登録していただく理由にします。

## できること

| 機能 | 内容 | 通数 |
|---|---|---|
| 友だち追加・ブロックの記録 | `follow` / `unfollow` を受けて D1 に反映 | 0通 |
| 空き枠のお知らせの受け取り申込 | リッチメニュー →自動応答→ ボタンでタグを付与 | 0通 |
| どちらのお部屋を希望されるか | 申込の直後にボタンで伺い、タグを付与 | 0通 |
| キーワード応答 | 予約・営業時間・アクセス・メニューなどに自動返信 | 0通 |
| 空き枠のお知らせ | スタッフ用ページから、希望された方にだけ送信 | 送った人数ぶん |
| 送信日の朝の声かけ | 月・木の朝、スタッフへ1通 | 月8通程度 |
| Instagram ストーリーズ | 画像と文面を生成（投稿は手動） | 0通 |
| 未対応質問の可視化 | 自動応答できなかった質問を集計 | 0通 |

自動応答できない質問には **あえて返信しません**。「わかりません」と返すより、
スタッフがLINEチャットで答えたほうが良いためです。LINEチャットの送受信も通数は無料です。

## 通数の考え方

ライトプランは **5,000通/月・追加購入なし**。上限に当たると月末まで一切送れません。
そのため送信前に必ず `src/quota.js` を通し、**予備枠500通を常に残します**。

さらに、同じお部屋のお知らせは **直近7日で3回まで**（`MAX_PER_WEEK`）。
続けすぎると「いつも空いている店」という印象になり、逆効果になるためです。
セルフブースと施術ルームは送り先が別なので、別々に数えます。

## セットアップ

### 0. Node.js をインストールする

<https://nodejs.org/> から LTS 版を入れてください。

```bash
node -v
npm -v
```

### 1. 依存をインストールして Cloudflare にログイン

```bash
cd C:/Users/ptkim/miele-line
npm install
npx wrangler login
```

### 2. D1 データベースを作る

```bash
npm run db:create
```

出力される `database_id` を `wrangler.toml` の `PASTE_DATABASE_ID_HERE` に貼り替えます。
続けてテーブルを作ります。

```bash
npm run db:init
```

### 3. 認証情報を登録する

[LINE Developers コンソール](https://developers.line.biz/console/) の
**Messaging API 設定** から、チャネルシークレットとチャネルアクセストークン（長期）を取得します。

```bash
npx wrangler secret put CHANNEL_SECRET
npx wrangler secret put CHANNEL_ACCESS_TOKEN
npx wrangler secret put ADMIN_USER        # スタッフ用ページのユーザー名
npx wrangler secret put ADMIN_PASS        # スタッフ用ページのパスワード（英数字で）
npx wrangler secret put STAFF_USER_IDS    # 朝の声かけを受け取るスタッフのLINEユーザーID（カンマ区切り）
npx wrangler secret put ADMIN_URL         # スタッフ用ページのURL。声かけの文面に入れる
```

### 4. 店舗情報を確認する

`src/salon.js` が店舗情報の唯一の置き場所です。営業時間・住所・電話番号などは
ここだけを直せば、自動応答にも画像にも反映されます。

**null のままの項目は、その話題の自動応答が無効になります。**
間違った内容を自動で答えてしまうより、スタッフに回したほうが安全なためです。
`diagnosisUrl` はコース診断ツールのLIFF URLで、発行後に入れると
リッチメニューとメニュー案内に自動で載ります。

### 5. デプロイする

```bash
npm run deploy
```

`https://miele-line.＜サブドメイン＞.workers.dev` が発行されます。

### 6. LINE公式アカウント側の設定

**LINE Developers コンソール（Messaging API 設定）**

- Webhook URL … `https://miele-line.＜サブドメイン＞.workers.dev/line/webhook`
- Webhookの利用 … オン
- 応答メッセージ … **オフ**（このシステムが返すため）
- あいさつメッセージ … **オン**（管理画面で文面を編集。通数は無料）

**LINE公式アカウント管理画面（リッチメニュー）**

リッチメニューのボタンは、管理画面では「リンク」「クーポン」「テキスト」
「ショップカード」「設定しない」から選びます。**postback は選べません。**
そのため空き枠のボタンは **テキスト** にして、`src/replies.js` の
`open_slot_optin` ルールが拾う言葉を送信させます。

画像は `design/richmenu.png`（2500×1686）を使ってください。
文言やボタンの割りつけは、デモの編集ページで作れます。

## 使い方

### スタッフ用ページ

```
https://miele-line.＜サブドメイン＞.workers.dev/admin
```

**店舗のパソコンのホームページに設定してください。** 開いた時点で
「本日は空き枠のお知らせの日です」が目に入るので、送り忘れを防げます。

1. どちらのお部屋か選ぶ（セルフブース／施術ルーム）
2. 空いている枠を入れる（日付・時間・枠の長さ）
3. その長さに入るメニューが自動で並ぶので、**機材の不調や材料切れのものはチェックを外す**
4. 「送る前に確認する」で、お送りする人数・通数・文面を見る
5. 送信 → 30分あけて Instagram に投稿

サロンボードから空きを自動で取る手段は公開されていません。また「空いている」枠が
すべて「出していい」枠とは限りません（移動・休憩・あえて残している枠が混ざります）。
そのため機械は **送り忘れだけを防ぎ**、どの枠を出すかは人が決めます。

### 自動応答できていない質問を見る

```
/admin/questions
```

よく聞かれるのに答えられていない質問が並びます。
`src/replies.js` の `RULES` に追加すれば、次から自動で答えられます。

```bash
npm run db:unmatched
npm run db:friends
npm run tail
```

### デモを作り直す

```bash
./build-preview.sh
```

`src/*.js` の本物のコードをそのまま埋め込んだデモが `out/` に出ます。
`out/index.html` が入口（空き枠デモ＋リッチメニュー編集ページ）です。

## 設計上の判断

**署名検証を必ず通す** — `X-Line-Signature` をチャネルシークレットでHMAC-SHA256検証します。
一致しないリクエストは401で弾きます。検証は `JSON.parse` する前の生ボディに対して行う必要があります。

**Webhookには即座に200を返す** — 応答が遅いとLINEがイベントを再送します。
`ctx.waitUntil` でレスポンス後に処理を続けます。

**同じイベントを二度処理しない** — 再送に備えて `processed_events` に `webhookEventId` を
記録し、既にあれば何もしません。送信側も `deliveries` の UNIQUE 制約で、
同じ人に同じ案内が二度届かないようにしています。

**空き枠の操作はスタッフ用ページで行う** — LINEのWebhookに届くのはお客様から届いた
メッセージだけで、スタッフが管理画面から送った返信はイベントとして飛んできません。
そのため「スタッフがトークに打ち込む」方式は成立しません。

**受け取り希望は一斉送信で募らない** — リッチメニューのボタン →自動応答→ ボタンで
タグが付きます。ここまで全部0通なので、稼働初日に希望者が0名でも困りません。

**「キャンセル」の語を使わない** — LINEの表示名はニックネームのことが多く、
その枠に入っていた方を個別に外すことはできません。代わりに文面から
「キャンセル」の語を外し、ご本人に届いてもご自身のことだと分からないようにしています。

**保存する個人情報を最小にする** — LINEのユーザーIDと表示名だけを持ちます。
氏名・電話番号・住所は保存しません。予約情報はサロンボード側に置いたままにします。
