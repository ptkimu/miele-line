第1部　オーナー様へ

導入のご判断に

何ができて、いくらかかり、何に気をつけるか

いまLINEでつながっているお客様は318名、Instagramのフォロワーは 1,019名です。このしくみは、その方々に向けて 空いてしまった枠をお知らせし、当日・数日先の予約を埋めるためのものです。

何をするしくみか

1. 空きを、欲しい方にだけお届けする

全員には送りません。リッチメニューから「空き枠のお知らせを受け取る」を 押してくださった方だけにお送りします。さらに、セルフブースと施術ルームの どちらを希望されたかで分けるので、関係のないお知らせは届きません。

2. Googleカレンダーから空きを拾う

月曜と木曜の朝10時、セラピストの皆さまのカレンダーを見て、空いている時間を拾います。 日付や時間を打ち込む必要はありません。

読むのは「その時間に予定が入っているかどうか」だけです。 予定のタイトルも、お客様のお名前も、こちらには届きません。 共有設定で「予定の表示（時間のみ）」を選ぶので、そもそも中身が渡らない仕組みです。

セラピストが2人いても施術ルームが1室であれば、どちらかに予定が入っている時間は 「埋まっている」と判定します。部屋数は設定で変えられます。

3. そのままLINEに送り、30分あけて外へ出す

送信の操作は要りません。拾った空きから3枠までを選び、 その時間に入るメニューを載せて、受け取りを希望された方にお送りします。 30分あけてから Instagram のストーリーズと Google の最新情報に出ます。

順番を守るのは、「LINEの方が30分早い」という事実をつくるためです。 これがLINEに登録していただく理由になります。

4. Instagram と Google にも、ひとりでに出る

LINEに送って30分後、Instagram のストーリーズと Google ビジネスプロフィールの最新情報に自動で出ます。 画像づくりも文面書きも要りません。

Google の投稿には「予約」ボタンが付き、店名と場所も添えます。 Googleマップの検索から来られた方に向けた文面になっています。

5. LINEの中で開くページ（6つのボタン）

リッチメニューの各ボタンから、LINEを離れずに開けるページです。 コース診断・メニュー料金・ご予約・問診表・空き枠の設定・アクセスの6つで、 それぞれがつながっています。

メニューの内容は1か所にまとめてあります。 料金が変わったときに直すのは1回で、診断・料金ページ・空き枠のメニュー候補の すべてに反映されます。3か所に書き写す作業はありません。

6. Instagram の文面と画像まで作る

枠を入れると、ストーリーズ用の画像（1080×1920）がその場で出来上がります。 ダウンロードして投稿するだけです。文字入れの手間はありません。

通数を使うのは空き枠のお知らせと朝のスタッフへの声かけだけです。 自動応答・あいさつメッセージ・LINEチャットでのやりとりは、何通でも無料です。

お客様に嫌がられないための工夫

空き枠のお知らせは、やりすぎると「いつも空いている店」という印象になり、 かえって予約が後回しにされます。歯止めを2つ入れています。

  • 同じお部屋のお知らせは、直近7日で3回まで。 定期の2回に、突発の1回ぶんの余地を足した回数です。 超えると画面に警告が出ます（セルフブースと施術ルームは送り先が別なので、別々に数えます）
  • 「キャンセル」という言葉を使いません。 文面は「空き枠のお知らせ」で統一しています。理由は次のとおりです

キャンセルされたご本人にも届いてしまう問題

LINEの表示名はニックネームのことが多く、サロンボードの予約者と突き合わせられません。 つまり「その枠をキャンセルされた方だけを外して送る」ことは技術的にできません。

そこで文面から「キャンセル」の語を外しました。 ご本人に届いても、ご自身のことだとは分かりません。 外せない機能を無理に作るより、届いても角が立たない文面にするほうが確実です。

お客様の情報の扱い

保存するのはLINEのユーザーIDと表示名だけです。 氏名・電話番号・住所・施術履歴は保存しません。予約の情報はサロンボード側に置いたままです。

お客様が「受け取りをやめる」を押されたら、その場でお知らせが止まります。 ブロックされた場合も自動で対象から外れます。

コース診断について

診断で残すのは選んでいただいた選択肢だけです （お悩み・ご予算・通い方・性別）。自由に入力していただく欄はありません。 もう一度診断されると、前回のタグは消えて新しいものに置き換わります。 お悩みが変わった方に、古い案内が届き続けないようにするためです。

問診表について — ここだけ扱いが違います

問診表は、アレルギー・お薬・妊娠といった健康に関わる内容をお預かりします。 ほかの機能とは扱いを分けています。

  • ご同意のチェックが無ければ受け取りません。何を何のためにお預かりするかを、 記入していただく前に画面でお示しします
  • 14日で自動的に消去します。スタッフがカルテに転記したあとは、こちらには残りません
  • LINEのトークには内容を残しません。スタッフには「届きました」とだけ通知し、 中身はスタッフ用ページでご確認いただきます

問診表を使わないという選択もできます。その場合はリッチメニューからボタンを外すだけで、 お預かりする情報はLINEのIDと表示名だけに戻ります。

第2部　スタッフの皆さまへ

毎日の使い方

月曜と木曜の朝、自動で動きます

送信の操作はありません。 月曜と木曜の朝10時、システムがカレンダーを見て、そのまま送ります。 スタッフの皆さまにお願いするのは 「カレンダーを正しく入れる」ことだけです。

月曜と木曜に起きること

スタッフの皆さまがすることは、ありません。 月曜と木曜の朝、システムがひとりでに動きます。 下は「裏側で何が起きているか」のご説明です。操作は不要です。

  1. 10:00　カレンダーを見る

    セラピストの皆さまのカレンダーから、2〜3日先の空いている時間を拾います。

  2. 10:00　出す枠を決める

    空きの中から3枠までを選び、その時間に入るメニューを載せます。 セルフブースと施術ルームは別々に判断します。

  3. 10:00　LINEに送る

    空き枠のお知らせを希望された方だけに届きます。 お部屋の希望を選ばれている方には、そのお部屋の枠だけが届きます。

  4. 10:30　Instagram と Google に出す

    ストーリーズ用の画像も自動で作られます。文面には 「LINEの方には30分前にお知らせ済みです」と入ります。

そのかわり、カレンダーが約束事になります

出したくない時間は、カレンダーに予定として入れておいてください。 移動・休憩・あえて残している枠を空けたままにすると、 空きとしてお客様にお知らせしてしまいます。

これが、人の確認を挟まないことと引き換えの、たったひとつのお願いです。

予定の名前は何でも構いません。「移動」「休憩」「ブロック」など、 分かるように入れておいていただければ大丈夫です。中身はこちらには届きません。

ちゃんと出たか確かめたいとき

スタッフ用ページを開くと、その週に何回出したかが分かります。 ご自身のLINEで受け取りを希望しておいていただくと、 お客様と同じものが届くので、いちばん確実です。

急な空きが出たとき

自動で動くのは月曜と木曜だけです。当日のキャンセルなど、 その場ですぐお知らせしたいときは、スタッフ用ページから手で出せます。 カレンダーから空きを取り込むボタンもあるので、入力は最小限です。

  1. お部屋を選ぶ

    セルフブースか施術ルームか。

  2. 「Googleカレンダーから空きを取り込む」を押す

    空いている時間が並びます。出したくない枠は「消す」で外してください。

  3. メニューのチェックを確認する

    機材の不調や材料切れのものは、チェックを外してください。

  4. 確認して送信する

    お送りする人数・残り通数・実際に届く文面が出ます。おかしければ戻れます。

ただし直近7日で3回を超えると警告が出ます。 自動で出したぶんも数に入ります。 その週にすでに何度も出している場合は、見送っていただくのが無難です。

メニューについて

自動で出すときは、その枠の長さに入るメニューが3つまで自動で載ります。 60分の枠なら、60分ちょうどのメニューが優先されます。

機材が不調のとき・材料が切れているときは、ご注意ください。 自動送信はその事情を知らないため、そのメニューを載せてしまいます。 しばらく使えないものがある場合は、お知らせください。 掲載メニューから一時的に外す（src/courses.js の1か所）ことができます。 手で出すときは、その場でチェックを外せます。

枠の長さを短くすると、入らなくなったメニューは自動で外れます。 60分の枠を30分に変えれば、60分のメニューは候補から消えます。

メニューを複数チェックすると、文面は 「いずれかをお選びいただけます」という書き方になります。 お客様がその場で決められなくても大丈夫なように、 「メニューはご来店時に決めていただいても大丈夫です」と添えてあります。

よくある質問

カレンダーへの入力が漏れていたら

埋まっている枠を「空き」としてお知らせしてしまいます。 これが完全自動でいちばん気をつけていただきたい点です。 ご予約が入ったら、これまでどおりその日のうちにカレンダーへお願いします。

変な枠が出てしまったら

送信済みのLINEは取り消せません。LINEチャットで訂正をお送りください。 Instagram と Google は30分後に出るので、 その前に気づけば止められます（ご連絡ください）。

しばらく自動送信を止めたいのですが

できます。止めている間も、スタッフ用ページから手で出すことはできます。 お知らせください。

予約が入ったら、システムに入力するのですか

いいえ。これまでどおり予約システムとカレンダーに入れてください。 このしくみはお知らせを出すだけで、予約は管理しません。

LINEのトークで返信が来たら

これまでどおり、LINEチャットからお答えください。送受信は何通でも無料です。 予約・営業時間・アクセスなど、よくあるご質問には自動で返信が出ます。 答えられない内容にはあえて返信しません。 間違った案内を出すより、直接お答えするほうが確実だからです。

間違った枠を送ってしまいました

送信済みのメッセージは取り消せません。LINEチャットで訂正をお送りください。 送信前の確認画面で、必ず文面をお読みいただくようお願いします。

お知らせを希望される方がまだいません

稼働の初日は0名です。リッチメニューの「空き枠のお知らせ」ボタンと、 友だち追加時のあいさつメッセージから増えていきます。 どうしても最初に呼び水が必要な場合は「希望していない方にも送る」 というチェック欄がありますが、ブロックされやすくなります。 稼働の直後だけにしてください。

第3部　設定される方へ

LINE公式アカウント側の設定

システム側だけでは完結しません。管理画面での設定が3つあります

1. リッチメニュー

LINE公式アカウント管理画面の ホーム ▸ リッチメニュー で作成します。 画像は 2500×1686 のものをご用意しています。

管理画面でボタンに設定できる種類は、リンク／クーポン／テキスト／ショップカード／ 設定しない の5つだけです。開発者向けの postback は選べません。

そのため空き枠のボタンは 「テキスト」 にしてください。 お客様が押すと決まった言葉が送信され、システムがそれを拾って 「受け取りますか」のボタンをお返しします。ここは自動応答なので通数は0通です。

文言やボタンの数は、デモの編集ページで変えられます。 変えた内容がそのまま設定手順に反映されるので、画面を見ながら管理画面に写してください。

2. あいさつメッセージ

ホーム ▸ あいさつメッセージ をオンにしてください。通数は無料です。 ここに「空き枠のお知らせを受け取れます」の一文を入れておくと、 友だち追加のたびに希望者が増えていきます。文面はオーナー様・スタッフの皆さまで 自由に編集していただけます。

3. 応答メッセージ

ホーム ▸ 応答設定 で、応答メッセージをオフ、 Webhookをオンにしてください。 両方オンにすると、同じ質問に二重で返信してしまいます。

LINEチャット（手動での返信）は、これまでどおりお使いいただけます。 Webhookをオンにしても、スタッフの返信が妨げられることはありません。

第4部　設定される方へ

つなぎこみの手順

予約システム・Googleカレンダー・自動投稿・LIFF の4つです

1. 予約システムのURLを入れる

ご予約の入口は src/salon.js の bookingUrl 1か所だけです。 ここを書き換えると、自動応答・リッチメニュー・空き枠のご案内のすべてが同じ入口を指します。 書き写す場所はほかにありません。

書き方

bookingUrl: 'https://＜予約システムのURL＞',

クーポンのページが別にある場合は couponUrl にも入れてください。 null にすると、URLを出さずに「お電話・LINEで承ります」に変わります。 間違ったURLをご案内するより、そのほうが安全です。

ご予約フォームはこちらでは作りません。 独自のフォームを作ると、予約が予約システムに入らず、 同じ枠が二重に売れてしまいます。すでにお使いのシステムへお通しするのが確実です。

2. Googleカレンダーをつなぐ

Googleの審査はありません。 お客様にGoogleへログインしていただく作りであれば審査が必要になりますが、 このしくみはサービスアカウントという、システム専用の利用者を1つ作って カレンダーを共有していただく方式です。同意画面が出ないため、審査の対象になりません。 費用も0円です。

  1. Google Cloud でプロジェクトを作る

    console.cloud.google.com で 新しいプロジェクトを作り、「Google Calendar API」を有効にします。無料です。

  2. サービスアカウントを作り、鍵を作る

    「IAMと管理 ▸ サービスアカウント」で1つ作成し、「鍵」タブから JSON形式の鍵を作ります。ダウンロードされたファイルの中に client_email と private_key が入っています。

  3. 各セラピストのカレンダーを共有する

    Googleカレンダーの「設定と共有 ▸ 特定のユーザーとの共有」で、 client_email のアドレスを追加し、権限を 「予定の表示（時間のみ、詳細は非表示）」にします。 これで予定の中身は渡らず、空いているかどうかだけが読めるようになります。

  4. Workers に登録する

    次の5つを登録します。鍵はコードには書きません。

名前入れるもの
GOOGLE_SA_EMAIL鍵ファイルの client_email
GOOGLE_SA_KEY鍵ファイルの private_key（BEGIN から END まで丸ごと）
GOOGLE_CALENDARSどのカレンダーがどの部屋か。
[{"id":"a@…","room":"room","label":"Aさん"},{"id":"self@…","room":"self","label":"セルフ"}]
ROOM_CAPACITY同時に施術できる数。{"room":1,"self":1}
セラピストが2人いても施術ルームが1室なら room は 1 です
SLOT_BUFFER_MIN予定の前後にあける時間（片付けなど）。既定は 0

出したくない時間は、カレンダーに予定として入れておいてください。 移動・休憩・あえて残している枠は、何も入っていなければ「空き」として拾われます。 ブロックしておけば、候補にも出ません。

設定が済むまでは、スタッフ用ページは手入力のまま動きます。 つなぎこみを待たずに運用を始めていただけます。

3. Instagram と Google への自動投稿

ここはオーナー様の作業です。お店のアカウントの持ち主でないと、 許可を出せないためです。取れた値をお知らせいただければ、あとはこちらで登録します。

Instagram

Facebookページは不要です。 「Instagram API with Instagram Login」という、Instagramだけで完結する方式を使います。

  1. プロアカウント（ビジネス）にする

    ストーリーズのAPI投稿はビジネスアカウント限定です。 「クリエイター」では投稿できません。

  2. Meta で アプリを作り、Instagram を連携する

    必要な権限は instagram_business_basic と instagram_business_content_publish の2つです。

  3. アクセストークンとユーザーIDを控える

    IG_ACCESS_TOKEN と IG_USER_ID になります。 トークンには期限があるので、切れたら入れ替えが必要です。

ストーリーズ画像の置き場（Vercel）

Instagram は「公開URLにあるJPEG」しか受け取りません。 Cloudflare には絵を描く仕組みがないため、画像を作る部分だけ外に置いています。

GitHub のリポジトリに renderer/ というフォルダが入っています。 Vercel から同じリポジトリを選び、ルートディレクトリに renderer を指定してデプロイしてください。発行されたURL （https://＜アプリ名＞.vercel.app/api/story）が STORY_IMAGE_URL になります。無料の範囲で収まります。

設定しなくても止まりません。 その場合は Instagram だけ見送り、Google には文面で投稿します。

Google ビジネスプロフィール

投稿APIの利用申請は承認済みとのことなので、あとは許可を出すだけです。 カレンダーと違い、サービスアカウントは使えません。 店舗を管理しているGoogleアカウントで、一度だけ許可を出していただく必要があります。

4. LIFF と LINEミニアプリ・審査について

コース診断やメニュー表を「LINEの中で開くページ」にする仕組みが LIFF です。 これには現在、審査はありません。チャネルを作ってLIFF IDを発行すれば使えます。

LIFF の設定

  1. LINE Developers で LIFF アプリを追加する

    Messaging API のチャネルに「LIFF」タブがあります。 エンドポイントURLは https://miele-line.＜サブドメイン＞.workers.dev/app/（末尾のスラッシュまで）、 サイズは Full、「ボットリンク機能」はオンにします。

  2. スコープを選ぶ

    profile と openid にチェックを入れます。 これで、どなたが診断をお受けになったかが分かり、タグを付けられるようになります。

  3. Workers に登録する

    LIFF_ID に発行された LIFF ID、 LIFF_CHANNEL_ID にそのチャネルのチャネルIDを登録します。 この2つが揃うまで、ページは「どなたか分からない」状態で開き、 診断の結果は出ますがタグは残りません。

  4. リッチメニューに割りつける

    各ボタンを「リンク」にして https://liff.line.me/＜LIFF ID＞/diagnosis の形で入れます。 後ろを menu intake slot access に変えると、 それぞれのページに飛びます。

LINEミニアプリへの統合について

LINEヤフー株式会社は、LIFF と LINEミニアプリのブランド統合を予定しており、 LIFF は LINEミニアプリに統合されると公式に案内しています （2025年2月12日のお知らせ）。公式ドキュメントにも 「新規にLIFFアプリを作成する場合は、LINEミニアプリとして作成することを推奨」 と書かれています。

ただし「この日でLIFFが使えなくなる」という期日は、現時点では公表されていません。 いま作ったものがすぐ使えなくなることはありませんが、 新しく作るなら最初からミニアプリとして作っておくほうが、あとの手間が減ります。

審査があるもの・ないもの

審査見え方・できること
LIFFなしいますぐ使えます
未認証ミニアプリなし どなたでも作れます。ヘッダーにタイトルとURLのドメイン名が出ます。一部機能に制限
認証済ミニアプリあり 認証バッジが付き、LINEアプリ内の検索に載ります

ミエーレの場合、まずは審査の要らない範囲で十分です。 診断・メニュー表・アクセスは、未認証のままで問題なく動きます。 「LINEの検索から新しいお客様に見つけてほしい」となった段階で、認証を取りにいくのが順番として自然です。

認証済ミニアプリの審査を受けるときの手順

  1. 準備する

    チャネルの基本情報、権限設定、アプリの説明文、 利用規約とプライバシーポリシーのURL をそろえます。 ガイドライン（アイコン・読み込み中の表示・動作速度など）への適合も確認します。

  2. ご予約を含む場合はテスト手順を用意する

    「予約・決済・注文」を扱うサービスは、審査担当者が実際に試すための テストシナリオの提出が求められます。ミエーレでご予約への導線を入れる場合は、ここが該当します。

  3. LINE Developers コンソールから申請する

    「審査申請」タブに必要事項を入力して申請します。

  4. 結果を待つ

    通常1〜2週間です。差し戻しがあると、修正して再申請するぶんの日数が加わります。 結果はメールとコンソールの通知で届きます。

  5. 通ったら公開する

    初回は「検索可能にする」ボタンを押すと、LINEアプリ内の検索に載ります。 更新の場合は「変更を公開」を押します。 押さないままでも、31日目の朝9時に自動で公開されます。

審査を受ける前に、利用規約とプライバシーポリシーをご用意ください。 問診表を入れる場合は、そこに「何を、何のために、どのくらいの期間お預かりするか」を 書いておく必要があります。
